# 问间官网

网站地址：<https://largetomatoes.github.io/wenjian/>。GitHub Pages 从 `main` 分支根目录发布，使用原生 HTML、CSS、JavaScript，不需要构建或第三方前端依赖。

## 页面结构

- 首屏：可点击的问题树与交叉联系，卡片可以演示关联到问题。
- 阅读：电脑端 PDF / EPUB 对照阅读实机截图。
- 成文：随手记录、关联问题、共同思考、选入文稿的交互示意，段落来源按需展开。
- 形成过程：保留最初记录、后续理解和修改原因的示意。
- 辅助能力、本地资料、各平台下载与常见问题。

交互演示使用虚构记录，没有上传表单、个人资料、账号或数据同步。它用于介绍软件，不是在线版问间。

## 本地预览

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8080/>。

发布新应用版本后，在 `index.html` 中更新各平台版本与直接下载链接。桌面和 Android 的附件分别核对，不能假定最新桌面发行版一定包含 Android 安装包。截图使用虚构测试资料，避免把个人笔记放到公开官网。

3.1起公开版本按圆周率前缀推进，内部构建号独立递增。网站不含个人资料或账号。

当前维护构建：3.14（319），云格式4。三端链接采用build319独立附件，完整源码标签为v3.14-build319。更新共同笔记、卡片编辑/标签/归档、首启来信与同版本构建更新说明；新截图均来自虚构测试资料。
